## 1. 目的与范围
- 目的:让每个候选在进入「同意 1」之前有一个**可复算**的毛利;算不出来时必须 `UNKNOWN` 并停住,不许用默认值凑数(INV-10)。
- 范围(做):`03 §3.1` 的 c1〜c16、revenue/profit/margin、逐项取整、缺失即 UNKNOWN、`tax_regime` 枚举与 `ASSUMED_WORST`、每项带来源与新鲜度。
- 范围(不做):汇率自动获取、打分排序、数据库持久化、REST/画面。
- 使用者(角色):Operator(通过后续的候选详情确认毛利),系统(同意 1 的前置)。
- 相关画面与功能:暂无画面;将来挂在 SCR-03 候选详情。

## 2. 现状与问题
| No | 现在的做法 | 遇到的问题 | 影响 |
|---|---|---|---|
| 1 | 毛利靠手工 Excel 拼 | 口径不统一,退货损耗与佣金容易重复扣 | 决策依据不可信 |
| 2 | 缺运费/税率时常「先估一个数」 | 数字看起来合理但不可复算 | 违反 INV-10,人无法核对 |

## 3. 业务需求
| BR 编号 | 业务上需要能做到什么 | 业务流程的环节 | 优先级 |
|---|---|---|---|
| BR-4-01 | 看到一个候选的毛利,并能逐项展开核对来源 | 选品 → 同意 1 | 高 |
| BR-4-02 | 数据不全时系统明确说「缺哪几项」,而不是给个假数 | 选品 → 缺口队列 | 高 |

## 4. 功能需求
REQ 编号在 02、03 里使用(CI 的 trace 按它对应)。本期无画面,验收以测试输出与成本分项的结构为准。

| REQ 编号 | 需求 | 验收条件 | 画面与 API |
|---|---|---|---|
| REQ-4-01 | 采购价、国内运费、国际运费的到岸成本计算 | 给定固定输入,计算结果与手算一致(JPY 整数) | `costing.compute` |
| REQ-4-02 | 关税、输入消费税、通関费、包材的计算,受 `tax_regime` 驱动 | `tax_regime=UNKNOWN` 时这四项不产出数字,整体 UNKNOWN | `costing.compute` |
| REQ-4-03 | 佣金、支付/跨境手续费、退货损耗、结算费、发出件损耗、样品摊销、达人/广告/活动 | 每项只扣一次;c10 已含退款对营收的扣减,不再并入到岸成本 | `costing.compute` |
| REQ-4-04 | 逐项四舍五入到 JPY 整数后求和,再推导 revenue/profit/margin | 同一组数据,「逐项取整」与「先求和后取整」结果不同的用例里,程序取前者 | `costing.compute` |
| REQ-4-05 | 任一 `BLOCKING` 项缺失 → `status=UNKNOWN` 且 `missing[]` 列出缺项 | 删掉任意一个 BLOCKING 项,结果不得出现 profit 数字 | `CostResult` |
| REQ-4-06 | `tax_regime` 六态枚举与有效期;`ASSUMED_WORST` 时结果标 `assumed=true` | 切换枚举,四项税相关成本按对应口径变化;`ASSUMED_WORST` 不被当成确认值 | `TaxRegime` |
| REQ-4-07 | 每个成本项都带 `source` / `fetched_at` / `status` | 任取一项都能说出「这个数从哪来、什么时候取的」 | `CostItem` |
| REQ-4-08 | 结果引用 `fx_rate_id` 快照,金额不接受 float | 传入 float 立即报错;快照 id 出现在结果里 | `CostResult` |

## 5. 非功能需求
| 分类 | 需求 | 目标与标准 |
|---|---|---|
| 性能 | 单候选成本计算 | < 5ms(纯内存计算) |
| 安全 | 金额不用 float;不调用 LLM / 网络 | INV-8 / INV-16 的静态检查覆盖 |
| 易用性 | 缺项信息能直接告诉人「去哪补」 | `missing[]` 带配置项 key |
| 运维 | 无状态、可重复计算 | 同一输入永远同一输出(属性测试) |

## 6. 约束与前提
- 公式唯一出处是 `design/ai/03_业务主线与规则.md §3.1`;本模块不得另立公式。
- `tax_regime` 与费率卡的来源/新鲜度由人维护,系统不猜。
- 汇率与货源的新鲜度检查已由 `04` 内核的 PC-* 承担,本模块只引用快照 id。

## 7. 术语
| 术语 | 含义 |
|---|---|
| 到岸成本 | c1–c7 的小计(不含佣金与退货损耗) |
| BLOCKING | 缺失即令利润不可算的成本项级别 |
| ASSUMED_WORST | 外部答复未到时人选的「最坏情形」口径,只能更严 |
