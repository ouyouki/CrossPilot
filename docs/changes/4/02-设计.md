## 1. 接缝(测试放在哪)

只有一个公开接缝:**`costing.compute(input) -> CostResult`**。
测试只调它,不碰内部函数;内部可以整个重写而不改测试。

## 2. 接口的三个候选与选择

| 候选 | 形状 | 能抓到 | 抓不到 |
|---|---|---|---|
| A. 一个函数吃一切 | `compute(rate_card, facts, tax, fx) -> CostResult` | 全部成本规则、缺失语义 | — |
| B. 每项一个公开函数 | `calc_c1(...)`、`calc_c2(...)` … | 单项精确 | 组合语义(逐项取整、缺失传播、只扣一次)反而更难测 |
| C. 建表 + 查询 | `store.compute(candidate_id)` | 复用持久化 | 本期没有库,且把计算绑到存储上 |

**选 A**:唯一接缝、输入输出都是不可变值对象,B/C 的顾虑见方案 V2/V3。

```python
def compute(inp: CostInput) -> CostResult: ...
```

## 3. 数据结构

```python
class Severity(str, Enum): BLOCKING / OPTIONAL_ZERO
class ItemStatus(str, Enum): CONFIRMED / ESTIMATED / MISSING
class TaxRegime(str, Enum):
    DE_MINIMIS_EXEMPT / SELLER_IOR_DDP / SELLER_LIABLE_LOW_VALUE / PLATFORM_COLLECTS / ASSUMED_WORST / UNKNOWN

@dataclass(frozen=True)
class RateValue:            # 费率卡里的一项
    value: Decimal | None
    unit: str
    source: str
    fetched_at: datetime | None
    status: ItemStatus
    severity: Severity

@dataclass(frozen=True)
class FxRate: rate: Decimal; ref_date: date; source_id: str
@dataclass(frozen=True)
class IntlShipTable: tiers: tuple[tuple[int, int], ...]   # (max_weight_g, price_jpy) 升序

@dataclass(frozen=True)
class Assumptions:
    return_rate: Decimal           # r
    refund_commission_return: Decimal   # ρ,缺省 0 且标 UNVERIFIED
    unsellable_ratio: Decimal      # u
    order_units: int               # 每票件数,课税门槛用
    expected_sales: int            # c16 分母
    return_shipping_jpy: int       # L
    return_mode: str               # RETURN_TO_CN / DISPOSE_JP / REFUND_ONLY

@dataclass(frozen=True)
class ListingFacts:
    price_jpy: int                 # P,税込
    buyer_shipping_fee_jpy: int
    weight_g: int
    sample_cost_jpy: int
    hs_class: str

@dataclass(frozen=True)
class CostInput:
    rate_card: Mapping[str, RateValue]
    fx: FxRate
    tax: TaxRegime
    tax_effective_until: datetime | None
    listing: ListingFacts
    assumptions: Assumptions
    ship_table: IntlShipTable

@dataclass(frozen=True)
class CostItem:
    key: str          # c1_goods … c16_sample_amortization
    value_jpy: int | None
    unit: str
    source: str
    fetched_at: datetime | None
    status: ItemStatus
    severity: Severity

@dataclass(frozen=True)
class CostResult:
    status: str                    # COMPUTED / UNKNOWN
    items: tuple[CostItem, ...]
    revenue: int | None
    profit: int | None
    margin: Decimal | None
    missing: tuple[str, ...]
    assumed: bool
    fx_rate_id: str
    tax_regime: str
```

## 4. 处理流程

1. `tax == UNKNOWN` → 直接返回 `UNKNOWN`,`missing=("tax_regime",)`。
2. 逐项取费率卡:`status == MISSING` 且 `severity == BLOCKING` → 记入 `missing`。
3. `missing` 非空 → 返回 `UNKNOWN`(不产出任何金额),**不补默认值**。
4. 按 c1→c16 求值;`CNY × 汇率` 每一项先四舍五入到 JPY 整数。
5. 求和得 `profit`;`revenue` 按 `tax_regime` 决定是否含销项税;`margin = profit / revenue`(revenue 为 0 时 `margin=None`)。
6. `tax == ASSUMED_WORST` → `assumed=True`。

## 5. 权限与错误处理

- 无权限概念(纯计算)。
- 编程错误立即抛:`float` 金额 → `CanonicalisationError`(复用 `core.money`);未知 `cN` key → `KeyError` 带 key 名。
- 业务缺失不是异常:是 `status=UNKNOWN` + `missing[]`。
