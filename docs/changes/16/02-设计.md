## 1. 做法:能原样搬的都原样搬

| 对象 | 做法 | 理由 |
|---|---|---|
| 今日页标记 | `design/screens/01-today.html` 的 `<template id="main-tpl">` 逐字取出,存为 `pages/todayHtml.ts` | 这一步只要"像",不要"我重写得更好" |
| 右栏标记 | 同上,取 `detail-tpl` | 同上 |
| 页面级样式 | 取同一文件的 `<style>` 块,存为 `pages/today.css`,在 `cp2.css` 之后引入 | 原型把每页独有规则写在页面里,公共组件才在 `cp2.css` |
| 插画 / 图表 | `art.js`、`charts.js` 复制到 `frontend/src/vendor/`,挂载后调用 `CP.hydrateArt` / `CP.mountCharts` | 图表是用 canvas/SVG 手绘的,重写必然和原型不一样 |
| 外壳 | 照 `cp2.js` 注入的结构移植成 `<Shell>`:顶栏 + 左侧导航 + 主区 + 右栏 + toast + 换肤 | 结构一致,类名不变,样式直接复用 `cp2.css` |

## 2. 字体

原型 `<head>` 引 Google Fonts 的 IBM Plex Sans/Mono。本项目的验收要求"断网也能跑",所以:

- 从 Google Fonts 抓 `latin` + `latin-ext` 的 woff2(10 个文件,约 276KB),放进 `frontend/src/assets/fonts/`;
- 生成 `src/styles/fonts.css`(与官方 `@font-face` 同参数,只把 URL 换成本地);
- 假名与汉字仍走系统字体——原型的字体栈本来就是这样,IBM Plex 没有日文字形。
