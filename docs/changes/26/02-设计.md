## 2. 为什么不整块搬原型标记

原型的 `06-approvals.html` 有 293 行静态标记,其中一大块是**同意 2 的队列**和三张演示卡。我们目前只有同意 1 的数据:

- 整块搬 = 屏幕上出现不存在于系统的单子,和 #8 第一版犯的是同一个错(演示数据冒充真实数据);
- 数据驱动 = 少一点"原型里那些装饰",但每一条都是真单子。

所以这一屏是"**用原型的设计系统,渲染真实数据**"。等同意 2 做出来,再把队列那块按原型补齐。

## 3. 偏差

| 偏差 | 原因 |
|---|---|
| 没有"同意 2 队列"块 | 同意 2 还没做 |
| 没有快捷键盘(A/R/Space) | 属交互打磨,等这一屏用起来再补 |
| 右栏仍是原型静态说明 | 详情在主区展开,右栏暂不联动 |
