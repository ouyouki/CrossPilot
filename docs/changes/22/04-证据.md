## 开发期的失败与处置

| 失败 | 原因 | 处置 |
|---|---|---|
| POST 返回 501、`/api/v1/approvals` 404 | 端口上还跑着旧代码的服务(前一次启动的进程没退) | 结束残留 `python -m app.server` 进程后重启,新代码生效 |
| 候选行渲染成 0 条 | `status=UNKNOWN` 的行没有金额,原来的模板假设都有 | 生成行时按状态区分:可算的显示金额,不可算的显示缺项并禁用勾选 |
