# CrossPilot 的术语表

TikTok Shop 日本站(中国主体 + 跨境直邮 + 自己一家店)的自动运营系统:AI 干活,人只做两件事——批和给方向。

> 只收这个项目特有的业务用语,不写实现的细节。格式和规则见 `skills/domain-modeling/SKILL.md`。PM Agent 出方案时更新。

## 用语

**Pilot**:
项目经理 Agent:派活、打包审批单、汇总汇报。**没有批准权**(唯一例外是有效授权范围内代批同意 1)。
_不用_:管理员、调度器

**方向卡**:
人给经营方向的那张卡:类目、价格带、毛利底线、每日数量、避开项、权重。没有方向卡就不选品。
_不用_:配置、策略

**同意 1**:
选品同意(`ACT-SELECT`)。人批准哪些候选进入采集。
_不用_:审核、确认

**同意 2**:
素材与价格的同意(= 批准 `ACT-LIST-CREATE`,界面上叫"同意 2")。一品一单,永远不可授权。
_不用_:发布、上架确认

**闸门 / Gatekeeper**:
确定性判定器:输入动作 + 事实,输出 ALLOW / REQUIRE_HUMAN / BLOCK / HOLD。不调用大模型。
_不用_:检查器、风控

**挂起**:
等人或等输入时的等待态。**不会过期、不会自动放行**。不是审批状态,是叠加标记。
_不用_:超时、待定

**作废(VOID)**:
待批或已批准未执行期间,前置条件失效 → 旧单作废,对象回流水线重判,需要人批时生成带差异说明的新单。
_不用_:取消、撤销

**授权清单**:
人在批准时把"这一类"授权给系统代批的受限清单。只能收窄、24 小时后生效、≤30 天、有次数上限。
_不用_:白名单、免审

**执行清单**:
没有写接口时的上架方式(通道 A):把要填的字段整理成清单,人去卖家后台照做,回来回填实际值。
_不用_:操作手册、上架单

**读回核对**:
上架后拿平台上的实际值与批准值比对,不一致 → `READBACK_MISMATCH`,不得置 LIVE。
_不用_:验收、复查

**通道 A / B**:
A = 执行清单(人做最后一下);B = 写接口(系统做最后一下)。两者共用同一份载荷、审批规则与读回口径。
_不用_:方式一、方式二

**G0–G4**:
合规闸门分层:G0 类目准入 / G1 上架必备表示 / G2 文案 / G3 图片视频 / G4 平台规格。
_不用_:检查项、规则组

**到岸成本**:
`c1`–`c7` 的小计(采购价、国内运费、国际运费、关税、输入消费税、通関费、包材)。佣金与退货损耗单列,不并入。
_不用_:总成本、进货成本
