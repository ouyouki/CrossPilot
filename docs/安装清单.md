## 4. 需要你做的事（按顺序）

1. **仓库**：确认 `github.com/ouyouki/CrossPilot` 已存在。新建时**不要**勾选 README / .gitignore / license（否则推送要先合并）。
2. **推送 main**（唯一的直接推 main，之后规则集会禁止）：
   ```bash
   git remote add origin https://github.com/ouyouki/CrossPilot.git
   git push -u origin main
   ```
3. **三个 GitHub App**（Settings › Developer settings › GitHub Apps › New）：
   - 权限只给 Contents 读写、Issues 读写、Pull requests 读写、Metadata 只读；**不给** Actions / Workflows / Commit statuses / Administration
   - Webhook 关闭；只装本仓库
   - 记下 App ID、安装 ID、私钥 `.pem`
4. **三个环境**：三个系统用户（推荐）或三个容器；每个只放自己的私钥，设 `BOT_ROLE=dev|pm|review`；**不要** `gh auth login`、不要 `GH_TOKEN`
5. **仓库初始设置**（你自己的 gh 登录）：
   ```bash
   bash scripts/github/setup_repo.sh --dry-run   # 先看
   bash scripts/github/setup_repo.sh
   ```
   私有仓库若套餐不支持规则集，改在 Settings › Branches 用经典分支保护。
6. **仓库设置**：合并方式只留 squash；打开自动删分支；Actions 权限选 "Read repository contents"。
7. **建「每日计划」Issue** 并置顶（标题里要有「每日计划」）。
8. 之后建第一个需求 Issue（正文我给你）。
