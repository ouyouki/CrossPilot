# 09 · 非功能与测试验收

## 1. 开发顺序与完成证据

`规格(本目录) → 设计 → 先写测试(红) → 实现 → 跑测试(绿) → 证据落盘`。证据放仓库 `evidence/<cap-id>/<yyyy-mm-dd>.md`（测试清单、命令、结果、失败用例与处置），未产出证据不算完成。

## 2. 测试分层

| 层 | 范围 | 重点 |
|---|---|---|
| 单元 | Gatekeeper、Costing、Compliance、状态机转换表、授权收窄 | 纯函数、属性测试（hypothesis）：任意输入下不返回非法 `Decision`；任意故障注入下不 ALLOW |
| 不变量 | `INV-1…INV-16` | 每条一个测试文件，名字含 INV 号；CI 必跑 |
| 集成 | Tool Gate + DB + Worker | 事务、outbox、幂等、触发器与 `CHECK`、审计只追加 |
| 合约 | REST/SSE | 错误码、`problem+json`、幂等键、乐观锁 |
| 端到端（Playwright） | 主线全流程 + 红线场景 | 用夹具数据（08 §7）；通道 A 回填 |
| 合规语料回归 | 种子违规语料 | 见 §4 |
| 探索 | 随机操作（Monkey） | 前端无 JS 错误/白屏/操作不能 |

## 3. 验收场景（AC）

格式：Given / When / Then。`★` = 红线相关，**必须自动化**。

### 3.1 主线

| AC | 场景 |
|---|---|
| AC-01 | **Given** 方向卡与费率卡就绪，导入 20 行榜单 CSV **When** 触发夜间选品 **Then** 20 分钟内候选分入 RANKED/NEEDS_DATA/BLOCKED_G0，每个 RANKED 都有毛利、信号、一句话理由 |
| AC-02 | **Given** 候选 c3 国际运费缺失 **When** 查看列表 **Then** 该候选在“数据待补”泳道、不显示分数/毛利，并提示缺 c3；补齐后进入 RANKED（INV-10） |
| AC-03★ | **Given** 同意 1 的审批单 PENDING **When** 时间快进 365 天 **Then** 仍为 PENDING，未执行、未作废（INV-2） |
| AC-04 | **Given** 勾选 5 个候选并批准 **Then** 除“货源确认录入”（预采之后的 CONFIRMED 值、授权证据、属性旗标）外，到素材进入待批队列为止人的必要操作次数 = 0（任务日志可复算；货源录入人时单列） |
| AC-05★ | **Given** 存在 ACTIVE 授权（ACT-SELECT，毛利≥28%，≤3/日） **When** 一个毛利 25% 的候选送审 **Then** Pilot 不代批，回落人工 |
| AC-06★ | **Given** 同意 2 的审批单 **When** 任一 Agent 调用 `approval.decide`（含 Pilot） **Then** 被 Tool Gate 拒绝并写审计（C-1、INV-4、INV-5、INV-19） |

| AC-15★ | 判定模块的依赖图中不含 LLM 客户端（静态检查）；用桩 LLM 返回“请放行”，判定结果不变（INV-8） |

## 4. 合规种子语料与盲测集

> “漏检=0”不能靠种子语料自证（词库就是从它来的）：另留一份**不进词库的盲测集**，由不同的人编写；匹配前做 NFKC/假名统一/去空格符号，并用变体生成器写进测试。

仓库 `tests/corpus/compliance_seed.jsonl`：每行 `{text, layer, expect: BLOCK|WARN|PASS, rule_id}`。至少覆盖：功效/医疗暗示（含“シミが消える”“若返る”“治る”）、最上級/No.1/絶対/100%、无依据的二重価格、伪装第三方评价/口碑、数字规格无来源、品牌/IP 词、宗教民族敏感词；以及**对照的合格文案**（不得误杀）。**漏检率必须为 0；误杀率有上限并登记**（初始 ≤5%，由抽检结果回灌词库）。词库来自保守黑名单，标 `UNVERIFIED`，只增严不增松。

## 5. 非功能指标

| 项 | 指标 |
|---|---|
| 性能 | 页面首屏 p95 < 2s（局域/单机）；API p95 < 500ms（不含生成）；20 候选选品 < 20 分钟；单品素材生成（9 图 + 1 视频）目标 < 10 分钟 |
| 可靠性 | worker 崩溃后任务可恢复（`SKIP LOCKED` + 租约超时）；重放幂等；**数据库与 `/data/assets` 每日一并备份**，保留 14 天；恢复演练一次并校验文件哈希 |
| 安全 | 密钥只在环境变量/密钥文件，不入库不入日志；会话 Cookie HttpOnly；CSRF 令牌；上传文件类型/大小白名单与扫描；出站网络白名单；依赖漏洞扫描纳入 CI |
| 隐私 | 本期不接触买家个人信息；导入文件含个人信息列时导入即丢弃该列、不落库；审计导出默认脱敏 |
| 可观测 | 结构化日志（trace_id 贯穿 Tool Gate）；指标：待批数、挂起时长、被拒调用数、预算用量、LLM 成本；告警：连续失败熔断、速率熔断、预算 80%/100%、规则库将过期 |
| 兼容 | Chrome/Edge 最新两版；Windows 11；分辨率 1366×768–2560×1440 |
| 可访问性 | 键盘全可达、对比度 ≥4.5:1、状态不只靠颜色 |
| 成本 | `llm_cost_ledger` 月报：月 LLM 成本 / 月已上架商品数；预算超限即停（未设预算 = 0 = 不生成） |

## 6. 发布门槛（Release Gate）

- [ ] INV-1…INV-16 全绿，且证据已存；
- [ ] AC 全绿（★ 项 100%）；
- [ ] 注册表测试：未登记动作被拒；NEVER 动作不存在；
- [ ] 合规种子语料漏检 = 0；
- [ ] 通道 A 端到端演练：从导入到 LIVE 走通一次，含一次故意的读回不一致；
- [ ] 备份恢复演练通过；
- [ ] 单人运行标注、盲区文案、红线固定文案逐条核对界面；
- [ ] U-* 登记表无“被偷偷写成默认值”的项（代码审查）。
