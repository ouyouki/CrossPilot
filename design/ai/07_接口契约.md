# 07 · 接口契约

> 内部 REST（JSON）+ SSE。这是前端与后端的契约，也是自动化测试的入口。平台接口（通道 B）只定义适配器接口，P1 不实现。

## 1. 通用约定

| 项 | 约定 |
|---|---|
| 基础路径 | `/api/v1/shops/{shop_id}/…`（单店期只有一个 shop，但路径与服务端成员校验照做，并用 `(shop_id,id)` 复合外键防串店） |
| 认证 | 会话 Cookie（HttpOnly，SameSite=Lax）；本期账号由 Owner 创建；密码哈希 argon2；无第三方登录 |
| 授权 | 按 `members.role` 与动作注册表的 `approver_role`；服务端校验，前端隐藏不等于授权 |
| 幂等 | 所有 `POST` 写接口接受 `Idempotency-Key`，存 `idempotency_keys(user, endpoint, key, request_hash, response, state)`：同键同体 → 回放首次结果；同键不同体 → 422；同键处理中 → 409 |
| 并发 | 可变资源带 `version`/`ETag`；`If-Match` 不符 → `409 VERSION_CONFLICT` |
| 分页 | `?limit=&cursor=`；列表返回 `{items, next_cursor}` |
| 时间/金额 | ISO 8601 带时区（展示 `Asia/Tokyo`）；金额 `{amount:"1240", currency:"JPY"}` 字符串，不用浮点 |
| 错误 | `application/problem+json`：`{type, title, status, code, detail, rule_ids?, missing_facts?, next_action?}` |

### 1.1 错误码（节选）

| code | HTTP | 含义 |
|---|---|---|
| `BLOCKED` | 422 | 命中 BLOCK 规则；`rule_ids` 指明；不可忽略 |
| `HELD_UNKNOWN` | 409 | 缺事实/判定器不可用；`missing_facts`、`next_action` 告诉人补什么 |
| `NOT_APPROVED` | 403 | 红灯动作没有有效审批（INV-1） |
| `EVIDENCE_NOT_VIEWED` | 409 | 批准前未查看必看证据分区 |
| `PRECONDITION_FAILED` | 409 | 前置失效，审批单已 `VOID`，返回 `successor_id` |
| `NOT_GRANTABLE` | 422 | 试图把永不可授权动作加入清单 |
| `GRANT_WIDEN_FORBIDDEN` | 422 | 试图放宽授权（应新建） |
| `ACTION_FORBIDDEN` | 403 | 动作不存在或无权 |
| `BUDGET_EXCEEDED` | 422 | 预算/速率闸门（不暗示重试即可） |
| `READINESS_INCOMPLETE` | 409 | 开工前置清单未就绪 |
| `VERSION_CONFLICT` | 412 | 乐观锁/`If-Match` 不符（审批单版本或载荷哈希变了） |

### 2.7 审批与授权

| 方法 路径 | 说明 |
|---|---|
| `GET /approvals?status=&action_type=&sort=priority` | 待批队列（服务端优先级排序） |
| `GET /approvals/{id}` | 审批单：证据、前置条件当前值、必看分区 |
| `POST /approvals/{id}/view` | 前端上报已查看的证据分区 |

## 4. 适配器接口（对外部世界的边界）

```python
class ImportAdapter(Protocol):           # P1 实现：CSV / 粘贴 / 视觉
    def parse(self, payload: bytes, kind: str, mapping: dict) -> ParseResult: ...

class PlatformWriter(Protocol):          # P1：ChecklistWriter；P1.5：ApiWriter
    channel: Literal["A", "B"]
    def create_listing(self, payload: ListingPayload) -> WriteReceipt: ...   # A：生成清单与素材包，返回“待人执行”
    def read_back(self, ref: str) -> ReadbackValues | None: ...              # A：返回 None（由人回填）
    def delist(self, ref: str) -> None: ...                                  # P1.5

class LLMClient(Protocol):               # 仅 toolgate 内部可见
    def complete(self, prompt_id: str, version: int, data: dict, schema: dict) -> dict: ...
```

要求：`PlatformWriter.channel` 切换只影响“最后一下由谁完成”，**动作清单、审批规则、载荷、读回口径完全相同**；通道 B 实现后，A 的清单仍作为失败兜底保留。

## 5. 非功能约束（接口层）

- 单次请求 p95 < 500ms（不含素材生成）；素材生成走异步 `jobs`，接口返回 `202` + `job_id`；
- 20 个候选的选品运行（计时从“导入数据到位”起）< 20 分钟；
- 所有写接口 100% 产生审计行；
- 响应中不得出现密钥、LLM 原始提示词全文（审计里存 `prompt_id@version` 与数据哈希即可）。
