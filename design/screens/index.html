01

今日

今天该你做的几件事、流水线走到哪、哪里不对。

主按钮：去处理第一件打开 →
02流水线

方向

给方向：类目、价格带、毛利底线、数量、避开项、权重。

主按钮：保存方向打开 →
03流水线

选品

候选清单与数据缺口，勾选并发起同意 1。

主按钮：发起同意 1（勾 N 个）打开 →
04流水线

货源

录入货源、确认授权与属性，进采集箱。

主按钮：保存并确认货源打开 →
05流水线

素材

看素材、日文与回译、合规结果，退回或送审。

主按钮：送审同意 2打开 →
06治理

待批

统一的审批单：同意 1、同意 2、例外；挂起也在这里。

主按钮：批准打开 →
07流水线

上架

执行清单：照做、回填后台实际值、读回核对。

主按钮：复制全部并去后台打开 →
08治理

授权清单

Pilot 被授权代批什么，随时收窄或撤销；没有“放宽”。

主按钮：新建授权（经审批）打开 →
09治理

审计

谁、何时、依据什么、结果如何，含被拒绝的尝试。

主按钮：导出（脱敏，留痕）打开 →
10设置

设置

费率卡、白名单、店铺档案、规则库、安全带、Agent、预算、成员。

主按钮：保存打开 →
00入口

登录

账号密码 + 二步验证；含失败、锁定、忘记密码、首次激活五种状态。

主按钮：登录打开 →

如何读这套原型

一个颜色一个意思
左侧导航 = 流水线顺序方向 → 选品 → 货源 → 素材 → 上架；治理与设置在下方
琥珀 = 等你待批、挂起、数据待补
红 = 被拦不可售、规则命中、读回不一致
绿 = 已核对合规通过、读回一致、LIVE
换肤顶栏“换肤”按钮或 Alt+1–6，6 套配色，跨页记住
