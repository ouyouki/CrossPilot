## 一句话

AI 干活，人只做两件事：**批**（选品同意、素材与价格同意）和**给方向**（方向卡）。
不可撤回、系统拿不准的事一律停下交给人；判定由确定性规则产生，不由大模型产生。

## 阅读建议

- 老板/业务：先看 `docs/index.html` §1.1「现状与痛点」（为什么需要这套系统），再点开 `screens/index.html`。
- 想知道痛点与解法的一一对应：`ai/01_产品理念与红线.md` §0（来自 DeepSeek 版 §2）。
- 开发/AI：`ai/00_AI读我.md` → `01` → `04`（最核心）→ 其余按需。
- 想知道和 DeepSeek 版相比改了什么：`ai/10_决策记录.md`。
- 想知道还有哪些外部事实没核实、系统在未知期间怎么做：`ai/02_范围与阶段.md` §5。

## 说明

- 原型与文档中的数字为**演示数据**，不是平台事实。
- 日本站跨境店的时效、费率、禁限售、税务口径等外部事实**未核实**，设计里一律做成“配置项 + 缺失即阻断”，不填默认值。
- 本目录自成一体，不依赖也不修改任何其他项目的资产。
